## 宏量点云去噪与精简

- **[NV3D: Leveraging Spatial Shape Through Normal Vector-based 3D Object Detection](http://arxiv.org/abs/2510.11632v1)**  
  Krittin Chaowakarn, Paramin Sangwongngam, Nang Htet Htet Aung, Chalie Charoenlarpnopparut · 2025-10-13 · _cs.CV, cs.AI, cs.LG, I.2.6; I.2.9; I.2.10; I.4.8; I.4.10; I.5.1; I.5.4_  
  **AI 简报**：In this paper, we propose a novel model, NV3D, which utilizes local features acquired from voxel neighbors, as normal vectors computed per voxel basis using K-nearest neighbors (KNN) and principal component analysis (PCA). In addition, we applied element-wise attention fusion, which accepts voxel features as the query and value and normal vector features as the key, similar to the attention mechanism. In the validation set, NV3D without sampling achieves 86.60% and 80.18% mean Average Precision (mAP), greater than the baseline Voxel R-CNN by 2.61% and 4.23% mAP, respectively.

- **[PointMAC: Meta-Learned Adaptation for **Robust** Test-Time Point Cloud Completion](http://arxiv.org/abs/2510.10365v1)**  
  Linlian Jiang, Rui Ma, Li Gu, Ziqiang Wang et al. · 2025-10-11 · _cs.CV_  
  **AI 简报**：To address this limitation, we propose PointMAC, a meta-learned framework for robust test-time adaptation in point cloud completion. Point cloud completion is essential for robust 3D perception in safety-critical applications such as robotics and augmented reality. Our method optimizes the completion model under two self-supervised auxiliary objectives that simulate structural and sensor-level incompleteness.

- **[Have We Scene It All? Scene **Graph**-Aware Deep Point Cloud Compression](http://arxiv.org/abs/2510.08512v1)**  
  Nikolaos Stathoulopoulos, Christoforos Kanellakis, George Nikolakopoulos · 2025-10-09 · _cs.CV, cs.RO_  
  **AI 简报**：A folding-based decoder, guided by latent features and graph node attributes, enables structurally accurate reconstruction. In addition, it supports downstream applications such as multi-robot pose graph optimization and map merging, achieving trajectory accuracy and map alignment comparable to those obtained with raw LiDAR scans. We propose a deep compression framework based on semantic scene graphs.


## 几何特征/原始体拟合（法线/曲率/原始体/描述子）

- **[Spatial Forcing: **Implicit** Spatial Representation Alignment for Vision-language-action Model](http://arxiv.org/abs/2510.12276v2)**  
  Fuhao Li, Wenxuan Song, Han Zhao, Jingbo Wang et al. · 2025-10-14 · _cs.RO_  
  **AI 简报**：We propose Spatial Forcing (SF), a simple yet effective alignment strategy that implicitly forces VLA models to develop spatial comprehension capabilities without relying on explicit 3D inputs or depth estimators. Extensive experiments in simulation and real-world environments demonstrate that SF achieves state-of-the-art results, surpassing both 2D- and 3D-based VLAs. Vision-language-action (VLA) models have recently shown strong potential in enabling robots to follow language instructions and execute precise actions.

- **[rareboost3d: a synthetic lidar dataset with enhanced rare classes](http://arxiv.org/abs/2510.10876v1)**  
  Shutong Lin, Zhengkang Xiang, Jianzhong Qi, Kourosh Khoshelham · 2025-10-13 · _cs.CV_  
  **AI 简报**：To address this issue, we introduce a novel, synthetic point cloud dataset named RareBoost3D, which complements existing real-world datasets by providing significantly more instances for object classes that are rare in real-world datasets. To effectively leverage both synthetic and real-world data, we further propose a cross-domain semantic alignment method named CSC loss that aligns feature representations of the same class across different domains. Real-world point cloud datasets have made significant contributions to the development of LiDAR-based perception technologies, such as object segmentation for autonomous driving.
